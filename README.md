# Petko HA Add-ons

Repository for Home Assistant Supervisor — PostgREST, public API, DB admin, maintenance.

| Add-on | Uloga |
|--------|--------|
| `petko_postgrest` | API EN (port 3000, `petko_en`) |
| `petko_postgrest_sr` | API SR (port 3001, `petko_sr`) |
| `petko_public` | ngrok javni HTTPS |
| `petko_admin` | Adminer web UI (port 8080) |
| `petko_maintenance` | auto cleanup reči + izazova |

DB pristup: vidi [docs/DB-ACCESS.md](docs/DB-ACCESS.md)
